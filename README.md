# 🎮 Learn Quest – Serious Game Educacional 2D

**Learn Quest** é um *Serious Game educacional 2D* desenvolvido como **Trabalho de Conclusão de Curso (TCC)** para o curso de **Tecnólogo em Jogos Digitais – UniFacisa**.

O projeto tem como foco principal **auxiliar no aprendizado e no desenvolvimento cognitivo e motor de crianças com Síndrome de Down**, utilizando mecânicas simples, acessíveis e integradas à **Inteligência Artificial (IA)**.

---

## 📌 Sobre o Projeto

Learn Quest foi idealizado para ser um ambiente lúdico, inclusivo e educativo, onde a criança aprende enquanto joga.  
O jogo utiliza desafios progressivos que estimulam:

- 🧠 Cognição  
- 🗣️ Pronúncia e linguagem  
- 🖐️ Coordenação motora  
- 🔍 Reconhecimento de padrões  
- 🎯 Memória de curto e longo prazo  

O projeto se enquadra no gênero **Serious Game Educacional**, buscando ir além do entretenimento e atuar como uma **ferramenta de apoio ao desenvolvimento infantil**.

## 🎮 Modos de Jogo

O Learn Quest possui **quatro modos principais**, organizados por níveis de dificuldade:

### 🔤 Associação da Palavra à Imagem
O jogador deve montar corretamente a palavra correspondente à imagem apresentada, estimulando alfabetização e coordenação motora fina.

### 🧩 Labirinto
O jogador guia um personagem até o objetivo, desviando de obstáculos.  
Foco em raciocínio lógico e coordenação motora.

### 🧠 Desafio da Memória
Jogo da memória com níveis progressivos e limite de tempo, estimulando atenção e memória.

### 🗣️ Pronúncia Correta
Modo focado na fala e dicção, onde o jogador deve pronunciar corretamente o nome do objeto exibido, utilizando **IA para validação da resposta**.

---

## 🤖 Uso de Inteligência Artificial

O projeto utiliza recursos de **Inteligência Artificial da OpenAI**, incluindo:

- Geração de **imagens** (associação palavra-imagem)
- Geração e validação de **áudios**
- Validação da **pronúncia correta**
- Análise instantânea de respostas do jogador

⚠️ **Importante:**  
Este projeto depende diretamente de APIs da **OpenAI**. Caso os créditos da API estejam expirados ou indisponíveis, alguns modos podem **não funcionar corretamente**, especialmente:

- Pronúncia Correta  
- Associação da Palavra à Imagem
